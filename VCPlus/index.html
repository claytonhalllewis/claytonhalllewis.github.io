VC2: templatic generation from predictive regularities

The program predicts the next character of a string, one character at a time, using only regularities it finds in the string itself. Nothing is told to it about delimiters, spans, or templates. Type a letter string, or a word string (words separated by spaces), press Start, then Step.

Word string (items separated by spaces; recoded to letters):
Expected continuation (optional, used only by "Run to expected length" and the tests):

Current string

Prediction for the next character

Regularities applied at this step

Each regularity is a concrete pattern found in the string. "Condition" must be a suffix of the string for the regularity to apply; "context" is the earlier material it was derived from. Votes are weight × evidence. Two votes for the same character that read the same position of the string are the same evidence: only the larger is added.
